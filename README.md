# Ardyn Interiors — website

Single-page marketing site for **Ardyn Interiors**, an interior design studio
(organic materials, thoughtful functionality, timeless living). Plain HTML +
assets, no build step. Hosted free on **GitHub Pages**.

## Files
- `index.html` — the whole site.
- `assets/` — curated project photos + designer portrait.
- `assets/video/` — muted looping hero video (from the portfolio film) + poster.
- `.nojekyll` — serve files as-is on GitHub Pages.

## Brand
- Colors: deep teal-navy `#1C2A32`, warm greige `#9D9486`, gold `#DAB473`, cream `#F1EDE6`.
- Type: Cormorant Garamond (headings) + Jost (UI/body, standing in for the brand's "Now").

## Preview locally
```
python3 -m http.server 8000
```
Then open http://localhost:8000
